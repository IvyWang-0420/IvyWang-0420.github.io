## 1. 🔬 Meta 发布 Glimmer 开源权重 AI 模型，人人都可本地运行

**来源：TechCrunch**

Meta 正式发布 Glimmer，一款开放权重（open-weight）的 AI 模型，用户可免费下载并在自有硬件上运行。该模型与 Meta 内部更强大的 Muse Spark 形成对比——后者仅通过 API 提供。扎克伯格发表公开信称 AI 应"为所有人服务"，而非由少数实验室垄断。不过评论指出，这一愿景背后仍有不少附加条件。

📎 来源：TechCrunch

## 2. 💻 Perplexity 联手 Nvidia 推出本地 AI Agent——零 token 费用

**来源：VentureBeat**

Perplexity 与 Nvidia 深度合作，推出 Portable Computer 项目——一款完全本地运行的 AI Agent。所有模型、用户文件和任务均在设备端完成，不消耗任何计费 token。系统默认从本地启动，若需调用更强的云端前沿模型，才会请求用户授权。这是迄今为止将大规模 AI Agent 工作负载从云端迁移至本地设备最具野心的尝试。

📎 来源：VentureBeat

## 3. 🚗 小鹏让 AI 增加 30 秒记忆：自动驾驶开始理解时间

**来源：PingWest品玩**

## 4. 🤖 全球首个"零改造、全自主、全年无休"机器人餐厅落地上海

**来源：PingWest品玩**

AI 机器人公司 Sharpa 与 DQ 冰淇淋联合打造的全球首家机器人餐厅于 8 月 29 日在上海吴江路正式落成。Sharpa 机器人全自主完成一杯暴风雪冰淇淋从点单到交付的 55 步复杂流程（每日 10:00-22:00），使用为人类设计的工具和设备，无需人工持续操控。这是世界范围内机器人首次在真实商业门店中沿用全球统一标准设备完成连锁经营日常工作。

📎 来源：PingWest品玩

## 5. 💰 开源模型开始"收费"：Kimi K3、Qwen 调整商业许可证

**来源：PingWest品玩**

多家中国大模型公司悄然调整开源策略。Kimi K3 允许免费下载和商用，但若向第三方提供模型推理服务（MaaS）且公司年营收超过 2000 万美元，需另行签约。Qwen3.8-Max 进一步限制"AI Work Assistant"类编程/办公产品，门槛为 5000 万美元。DeepSeek V4-Pro 仍用 MIT 许可证，但同步将 API 高峰时段价格大幅上调 350%。许可证博弈正在成为模型公司商业竞争的新战场。

📎 来源：PingWest品玩

## 6. 🔒 Brave 浏览器新增邮件别名功能，对抗大数据追踪

**来源：The Verge**

隐私浏览器 Brave 推出邮件别名功能，用户可为不同服务创建一次性 decoy 邮箱地址，用于注册和登录。Brave 仍会转发这些服务的邮件至用户主邮箱，确保不错过重要通知，但有效阻断了大型科技公司的跨平台追踪。目前该功能已随隐私更新 39 号版本正式上线。

## 10. ⚙️ 企业 AI Agent 成败关键：限制自主权限比扩大权限更重要

**来源：VentureBeat**

VentureBeat 刊发企业 AI 深度分析：过去两年间，业界普遍认为"AI 自主性越高，性能越好"。但大规模真实生产环境测试表明，这一假设正在失效。成功部署 AI Agent 的企业并非给予 Agent 最大自由度，而是为每个 Agent 设定明确职责边界和操作规则。企业 AI 的核心竞争力将来自"规则设计"而非"模型选择"。
