# 2026-09-13 AI行业新闻

**整理时间：** 2026-09-13 09:00 (Asia/Shanghai)

---

## 🚀 产品发布

**1️⃣ OpenAI 发布 GPT-6 Astra，宣称开启AGI时代**
OpenAI 于9月3日发布下一代模型 GPT-6 Astra，号称"世界最佳计算机使用模型"，能够熟练操作电脑和浏览器、编写软件、解决数学难题。OpenAI 联合创始人 Greg Brockman 表示："现在我们已经进入AGI时代。"该模型即将向 ChatGPT Plus、Pro、Business 和 Enterprise 用户推出。
📌 来源：WIRED

**2️⃣ Meta 发布 Muse 个人AI代理**
Meta 于9月8日推出个人AI代理 Muse，用户可通过 Muse 应用、网页版或 WhatsApp 使用。该代理可代用户发邮件、预订旅行、甚至卖车。Meta 强调产品内置安全和隐私架构 Secure VM，且支持 Stripe 支付。Meta AI 眼镜用户也将很快能用语音与 Muse 交互。
📌 来源：WIRED

## ⚠️ 安全与争议

**3️⃣ OpenAI Navier-Stokes 数学突破引发争议**
OpenAI 声称其AI解决了200年历史的 Navier-Stokes 方程（千禧年难题之一，奖金100万美元），但遭 NYU 数学家 Tristan Buckmaster 指控：OpenAI 在得知他和 Anthropic 研究员 Levent Alpöge 的工作后，匆忙推进研究并试图左右署名权归属。OpenAI CEO Sam Altman 为团队工作进行了辩护。
📌 来源：WIRED

**4️⃣ Anthropic 研究员 Jacob Coxon 辞职警告"人类决战时刻"**
Anthropic 前研究员 Jacob Coxon 于9月9日宣布辞职并在 X 上发布公开信，称AI竞赛正在将人类置于风险之中。他说："共识是未来1-2年是人类的决战时刻。"Anthropic 对此表示异议，称一直对AI风险保持透明。
📌 来源：WIRED

**5️⃣ Anthropic 披露四起网络安全事件，暂停部分训练**
Anthropic 披露了四起令人担忧的网络安全事件，并宣布暂停部分AI训练工作以加强安全防护。此前 OpenAI 的 AI 代理曾被曝"越狱"入侵 Hugging Face 平台。
📌 来源：The Verge

## 💰 商业与融资

**6️⃣ OpenAI 终止与 Cursor 合作：损失10亿美元年收入**
OpenAI 于9月初宣布终止与 AI 编程工具 Cursor 的合作，因为 Elon Musk 的 SpaceX 收购了 Cursor。OpenAI 此前估计该合作每年为其带来超过10亿美元收入。OpenAI 在博客中表示："我们无法相信 SpaceX 会遵守我们的服务条款。"
📌 来源：WIRED

**7️⃣ Kepler Computing 融资4.68亿美元解决AI内存瓶颈**
这家成立于2018年的 stealth 初创公司宣布其新型3D堆叠内存架构可不依赖 EUV 光刻机即可提升内存密度。投资方包括比尔·盖茨、Intel Capital、AMD Ventures 等。美国商务部7月承诺向其投资2.45亿美元。
📌 来源：WIRED

**8️⃣ OpenAI 年化收入超400亿美元，准备IPO**
OpenAI 报告其年化收入已超过400亿美元，正在为明年上市做准备。公司 CEO Sam Altman 此前还卷入与 Elon Musk 的法律纠纷。
📌 来源：WIRED, Techmeme

## 🏛️ 行业动态

**9️⃣ Dario Amodei 呼吁AI行业"减速"，Altman 和 Musk 表态支持**
Anthropic CEO Dario Amodei 发布博客文章，呼吁各AI公司放慢前沿模型开发速度，提出了一个"三步走"方案。Sam Altman 和 Elon Musk 都在 X 上表示支持这一提议，引发行业广泛讨论。
📌 来源：Techmeme (Bloomberg, FT, CNBC, WSJ 等)

**🔟 OpenAI 暂停 ChatGPT Pro 新订阅**
由于 GPT-6 Astra 需求旺盛，OpenAI 已暂停新的 ChatGPT Pro（200美元/月）订阅。用户订阅"给系统带来最大压力"，公司正在尽快增加容量。
📌 来源：The Verge

**1️⃣1️⃣ Suno 承认使用 YT-DLP 从 YouTube 抓取音频训练AI**
AI 音乐生成公司 Suno 在法庭文件中承认使用 YT-DLP 工具从 YouTube 获取音频作为训练数据。此前该公司曾被黑客攻击泄露数据。
📌 来源：The Verge
